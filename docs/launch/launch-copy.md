### 正文

以前每天刷 AI 新闻，刷完还是不知道发生了什么。

所以我把「今日 AI 情报」整个换成了 **AI 投融资情报**：

💰 **重点投融资表**
日期 / 公司 / 融资金额 / 估值 / 方向 / 为什么值得关注 / 状态 / 来源
金额和估值分开，已确认、传闻、洽谈中分开标，不把估值当融资额。

🧠 **重要新模型表**
日期 / 模型 / 方向 / 核心变化，不写「更强了」这种空话。

🚀 **值得关注的新产品表**
Product Hunt 热榜，8 个 AI 新产品，每个都有中文速读。

📈 **3–5 个趋势信号**
不是复述新闻，而是：判断 + 本周证据 + so what + 反证/边界。

最关键的是：**每一条都有参考链接**，能点回原文核对。

它跑在 DeepSeek Harness 里，用当前账号分析；开源插件，数据按天保存。

GitHub：github.com/sunstdot/signalforge-dsh
